# 04.1 — Extensões do StudyPack para Origem, Qualidade, Dificuldade e Sugestões da IA

## 1. Objetivo do documento

Este documento complementa o documento 04 — StudyPack Format: Padrão de Arquivo de Questões.

Seu objetivo é definir extensões do StudyPack Format para representar origem do conteúdo, qualidade pedagógica, dificuldade original, sugestões da IA, status de revisão e aprovação humana.

Essas extensões garantem que conteúdos e questões importados, detectados ou sugeridos pela IA sejam tratados com transparência, controle e segurança pedagógica.

---

## 2. Por que o StudyPack precisa dessas extensões

O StudyPack Format precisa registrar a origem, o estado de revisão e as sugestões relacionadas a cada conteúdo, pois a plataforma trabalha com diferentes fontes:

- conteúdo original enviado em PDF;
- conteúdo reorganizado pela IA;
- conteúdo sugerido pela IA;
- conteúdo editado manualmente;
- conteúdo aprovado por professor/adulto;
- questões detectadas automaticamente;
- questões importadas;
- questões geradas como sugestão.

Sem esses metadados, o sistema perde rastreabilidade e dificulta a revisão humana.

---

## 3. Princípios das extensões

| Princípio | Descrição |
|---|---|
| **Transparência** | O sistema mostra claramente de onde veio cada conteúdo |
| **Não substituição automática** | Sugestões da IA não substituem conteúdo original |
| **Aprovação humana** | Conteúdo sugerido pela IA depende de aprovação do adulto |
| **Preservação da dificuldade** | Dificuldade original de questões é preservada |
| **Rastreabilidade** | Sistema registra origem, ações e relação com material original |
| **Interoperabilidade** | Campos estruturados para serem lidos pelo sistema, humanos e outras IAs |

---

## 4. Versão e novos campos

Essas extensões entram como **StudyPack versão 1.1**.

Novos campos no nível do pacote:

```json
{
  "studyPackVersion": "1.1",
  "contentOrigins": [],
  "aiSuggestions": [],
  "suggestedQuestions": [],
  "reviewWorkflow": {},
  "qualityRules": {},
  "difficultyPolicy": {},
  "auditTrail": []
}
```

O campo `studySections` é oficialmente parte do StudyPack a partir da versão 1.1.

O sistema deve aceitar StudyPacks sem campos de origem (retrocompatibilidade com versão 1.0).

---

## 5. Origem do conteúdo

### 5.1 Campo `origin`

Cada seção, tópico ou questão pode ter um campo `origin`. Apenas o adulto/professor vê essa informação — o aluno não.

| Código | Interface |
|---|---|
| `original_imported` | Original importado |
| `uploaded_pdf` | Enviado por PDF |
| `ai_reorganized` | Reorganizado pela IA |
| `ai_suggested` | Sugerido pela IA |
| `ai_rewritten` | Reescrito pela IA |
| `detected_from_pdf` | Detectado no PDF |
| `human_created` | Criado manualmente |
| `human_edited` | Editado manualmente |
| `human_approved` | Aprovado manualmente |

### 5.2 Exemplo em uma seção

```json
{
  "id": "section_001",
  "topicId": "topic_adjetivos",
  "title": "O que são adjetivos?",
  "contentType": "concept_explanation",
  "body": "Adjetivo é a palavra que caracteriza um substantivo...",
  "origin": "ai_reorganized",
  "sourceBlockIds": ["block_014"],
  "reviewStatus": "needs_review"
}
```

### 5.3 Exemplo em uma questão

```json
{
  "id": "q_001",
  "type": "multiple_choice",
  "topicId": "topic_adjetivos",
  "prompt": "Qual palavra funciona como adjetivo na frase abaixo?",
  "origin": "detected_from_pdf",
  "sourcePage": 5,
  "reviewStatus": "needs_review"
}
```

---

## 6. Status de revisão

### 6.1 Campo `reviewStatus`

| Código | Significado |
|---|---|
| `draft` | Rascunho |
| `needs_review` | Aguarda revisão humana |
| `reviewed` | Revisado |
| `approved` | Aprovado |
| `rejected` | Rejeitado |
| `published` | Publicado |
| `archived` | Arquivado |

### 6.2 Regra

> Itens com `needs_review` ou `draft` não devem ser publicados automaticamente para o aluno.

---

## 7. Preservação da dificuldade no StudyPack

### 7.1 Campos recomendados

```json
{
  "difficulty": "hard",
  "difficultySource": "human_defined",
  "aiSuggestedDifficulty": {
    "value": "medium",
    "confidence": 0.78,
    "reason": "A questão exige reconhecimento direto, sem raciocínio em etapas.",
    "status": "suggested"
  }
}
```

### 7.2 `difficultySource`

| Código | Significado |
|---|---|
| `human_defined` | Definido pelo professor/adulto |
| `imported` | Importado do arquivo original |
| `ai_inferred` | Inferido pela IA |
| `manually_adjusted` | Ajustado manualmente após importação |

### 7.3 Regra

> A IA pode sugerir dificuldade, mas não deve sobrescrever `difficulty` automaticamente quando definida por humano ou importada do arquivo. A mudança exige aprovação humana.

---

## 8. Políticas de qualidade no StudyPack

### 8.1 Campo `qualityRules`

```json
"qualityRules": {
  "preserveOriginalContent": true,
  "preventOverSummarization": true,
  "requireHumanApprovalForAISuggestions": true,
  "preserveOriginalDifficulty": true,
  "doNotAutoReplaceQuestions": true
}
```

Essas regras ajudam o sistema e outras IAs a entenderem como tratar o arquivo. Os valores acima são os recomendados para o MVP.

---

## 9. Sugestões da IA no StudyPack

### 9.1 Campo `aiSuggestions`

```json
{
  "id": "suggestion_001",
  "targetType": "study_section",
  "targetId": "section_001",
  "topicId": "topic_adjetivos",
  "suggestionType": "add_example",
  "title": "Adicionar exemplo cotidiano",
  "body": "Adicionar exemplos como 'casa bonita', 'menino feliz' e 'dia chuvoso'.",
  "reason": "A explicação está correta, mas pode ficar mais clara com exemplos simples.",
  "confidence": 0.88,
  "status": "suggested"
}
```

### 9.2 `targetType`

```
topic | study_section | question | answer_key | explanation | acceptance_criteria | exercise_set
```

### 9.3 `suggestionType`

```
add_example | add_explanation | add_common_mistake | improve_clarity | split_topic
merge_topics | suggest_question | improve_question | improve_explanation | review_difficulty
flag_ambiguity | flag_missing_answer_key | flag_low_quality
```

### 9.4 `status`

```
suggested | approved | rejected | edited | needs_revision | applied | archived
```

---

## 10. Sugestões de questões no StudyPack

Campo dedicado `suggestedQuestions`. Sugestões aprovadas são exportadas; rejeitadas, não.

```json
{
  "id": "suggested_question_001",
  "topicId": "topic_adjetivos",
  "type": "fill_blank",
  "difficulty": "easy",
  "prompt": "Na frase 'O cachorro bravo latiu', a palavra ________ é um adjetivo.",
  "answerKey": {
    "acceptedAnswers": ["bravo"],
    "caseSensitive": false,
    "ignoreAccents": true
  },
  "explanation": "Bravo é adjetivo porque caracteriza o substantivo cachorro.",
  "reason": "Criar uma questão mais simples antes da questão difícil original.",
  "origin": "ai_suggested",
  "reviewStatus": "needs_review"
}
```

> Questões em `suggestedQuestions` não devem ser exibidas ao aluno até aprovação humana.

---

## 11. Auditoria

### 11.1 Campo `auditTrail`

O audit trail fica apenas no banco — não é exportado no arquivo StudyPack.

```json
{
  "id": "audit_001",
  "action": "ai_suggestion_approved",
  "targetType": "question",
  "targetId": "suggested_question_001",
  "userId": "teacher_001",
  "timestamp": "2026-05-16T10:00:00Z",
  "notes": "Questão aprovada após edição manual."
}
```

### 11.2 Ações possíveis

```
created | imported | ai_reorganized | ai_suggestion_created | ai_suggestion_approved
ai_suggestion_rejected | human_edited | human_approved | published | archived
```

## 13. Regras para IA externa gerar StudyPack 1.1

1. Não remover conteúdo essencial do material original.
2. Não resumir excessivamente explicações importantes.
3. Preservar dificuldade informada pelo usuário.
4. Não substituir questões originais por versões próprias.
5. Criar sugestões em `aiSuggestions` ou `suggestedQuestions`.
6. Marcar conteúdo gerado com `origin` apropriado.
7. Marcar tudo que precisa de revisão com `reviewStatus: needs_review`.
8. Não inventar gabaritos sem base no material.
9. Não alterar resposta correta sem sinalizar alerta.
10. Usar `qualityRules` para respeitar a política do pacote.

---

## 14. Validação do arquivo com extensões

### 14.1 Erros que impedem importação

```
A sugestão suggestion_001 aponta para uma section inexistente.
A questão suggested_question_001 não possui answerKey.
```

### 14.2 Warnings

```
A questão q_001 possui dificuldade original hard, mas a IA sugeriu medium. Revise antes de publicar.
A seção section_001 foi reorganizada pela IA e ainda precisa de revisão humana.
```

### 14.3 O validador deve verificar

- se `origin` usa valor permitido;
- se `reviewStatus` usa valor permitido;
- se sugestões apontam para targets existentes;
- se sugestões possuem justificativa;
- se questões sugeridas possuem gabarito;
- se dificuldade original não foi sobrescrita indevidamente;
- se itens sugeridos não estão publicados automaticamente;
- se `qualityRules` estão presentes quando aplicável.

---

## 15. Critérios de aceite

### Origem e revisão
- O StudyPack permite registrar origem de tópicos, seções e questões.
- O StudyPack permite registrar status de revisão.
- Itens com `needs_review` não são publicados automaticamente.

### Dificuldade
- O StudyPack preserva dificuldade original.
- A IA registra dificuldade sugerida sem sobrescrever a original.
- Mudança de dificuldade exige aprovação humana.

### Sugestões
- Sugestões da IA ficam em lista separada com target, tipo, justificativa e status.
- Questões sugeridas ficam separadas das questões aprovadas.
- Sugestões não aparecem para o aluno até aprovação.
- Sugestões aprovadas são exportadas; rejeitadas, não.

### Validação
- O sistema valida campos de origem e status.
- O sistema valida targets das sugestões.
- O sistema sinaliza conflitos de dificuldade.
- O sistema impede publicação automática de conteúdo sugerido não aprovado.

## 16. Decisões tomadas

| Questão | Decisão |
|---|---|
| Versão das extensões | StudyPack 1.1 |
| `studySections` é campo oficial? | Sim, a partir da versão 1.1 |
| Sugestões aprovadas são exportadas? | Sim |
| Sugestões rejeitadas são exportadas? | Não |
| Aluno vê origem do conteúdo? | Não — apenas o adulto |
| `qualityRules` é obrigatório? | A definir |
| Sistema aceita StudyPacks sem campos de origem? | Sim (retrocompatível com v1.0) |
| Audit trail no arquivo exportado? | Não — apenas no banco |
